# GMOS LIA Board (KiCad project)

KiCad project of the LIA readout board for the GMOS gas sensor.

| Path | Contents |
|------|----------|
| `GMOS-LIA.kicad_pro`, `*.kicad_sch`, `*.kicad_pcb` | KiCad project, schematic sheets, layout |
| `device_libraries/` | Project symbol libraries |
| [docs/](docs/README.md) | Design documentation: requirements, theory, schematic overview, task list, firmware, lab tests, decision log, references |
| [tools/](tools/README.md) | Netlist query and check tools (`netquery.py`, `netcheck.py`, `checks/Txx*.txt`) |
| [CLAUDE.md](CLAUDE.md) | Working rules for Claude Code on this project |

Simulations of the front end are in [`simulations/`](../../simulations/README.md). The MCU firmware project is in [`firmware/`](../../firmware/).
