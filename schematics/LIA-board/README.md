# GMOS LIA Board — Overview

KiCad project for a GMOS gas-sensor readout board based on the lock-in amplifier (LIA) principle. The board replaces the bench setup (SR860 lock-in, SR560 pre-amplifier, lab supplies) used for the 3T differential measurement of the GMOS active/blind transistor pairs.

> **Status (2026-10-20):** schematic capture in progress (12 sheets). Documentation restructured; several architecture decisions changed in this revision (MCU-generated excitation, STM32U575, one switched active/blind pair, 1× DAC80508). See [schematic_review.md](schematic_review.md) for the netlist punch list and the work order.

### Conventions

- Every file starts with `# GMOS LIA Board — <Topic>`; chapters are `##`, sections `###`, subsections `####`. No other `#` headings.
- Requirement IDs (`DC-n`, `AN-n`, `DG-n`) are defined only in requirements.md. Design text quotes the ID, not the value, unless the value is needed for a calculation.
- Tags: `TODO` = work to be done; `ASSUMPTION` = value used for sizing, to be confirmed; `DECISION` = a choice recorded in §9.1; `CHANGED` = requirement changed in the current revision (requirements.md change log).
- Dates `YYYY-MM-DD`. Units with a space (`330 kΩ`, `5 mVpp`). Amplitudes always state `pp`, `pk` or `rms`.
- Reference designators in the text must match the netlist. When a part is renamed in KiCad, search the docs for the old designator.

## Architecture at a Glance

The gate of all six pixels is driven by a DAC80508 DC level plus a sine generated by the MCU DAC; one active pixel (1–3) and one blind pixel (4–6) are selected at a time by two dual 4:1 multiplexers, which connect drain and heater of the selected pixels to one heater driver and one drain supply per side (all other pixels disconnected); the drain nodes (or a calibration tone) feed an INA828 → band-pass → AD630 X/Y lock-in → ADS1220 chain; the MCU (STM32U575, 16 MHz XO) generates excitation and references and streams X/Y to the PC over an isolated UART. The block diagram is in [§4.2](schematic_overview.md#42-signal-chain-overview).
