## Options (decision topic)
- Option Fixed: keep the band-pass fixed at 518 Hz (equal-component FE-B/C per S24-F04, or unity-gain FE-A per S24-F06). Other frequencies are handled by re-tuning R and C (S24-F12) and by calibration of gain and phase (S24-F11, S24-F13). Risk: each frequency change needs new R/C values and calibration, and gain and phase move along the Q curve (S24-F11, S24-F12); the docs give no re-tune procedure (S24-NF05).
- Option Switchable: switch between preset filter sets (named in README §9.2 item 6, S24-F29). Risk: the listed docs contain no design, values, or noise and harmonic data for a switchable filter (S24-NF04, S24-NF01), so it cannot be graded from the docs.
- Option Wide (lower Q, e.g. Q 0.707): no re-tune across a `318–843 Hz` −3 dB band (S24-F14). Risk: relative to Q 1 it gives 4 dB less attenuation at 2f₀, 6 dB less at 3f₀ and 6–7 dB less at 150 Hz and 50 Hz (S24-F15, S24-F16), so more mains and harmonic content passes; the owner's "may still work" is not in the docs (S24-NF02). In the equal-component form it needs `K ≈ 1.59` (S24-F25), which the docs do not evaluate.
