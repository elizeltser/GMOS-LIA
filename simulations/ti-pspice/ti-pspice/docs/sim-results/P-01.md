# P-01 Validation of the shorter run settings

## Goal

Check that the default settings (1 s, `.IC` at 2.5 V, 20 us step) give the same settled values as a 2 s run from 0 V. If they do, every later test uses them.

## Runs

| Run | Command | Simulated time | Wall time |
|---|---|---|---|
| A | `python tools/run_sim.py circuits/lia_baseline.cir --name P01_A_2s_from0 --analysis ".TRAN 0 2 0 20u SKIPBP" --extra ".OPTIONS NUMDGT=8" --probe "V(VX)" "V(VY)" "V(VX_DEMOD)" "V(N00261)"` | 2 s, no `.IC` | 143 s |
| B | Same as A with `--name P01_B_1s_ic`, `--analysis ".TRAN 0 1 0 20u SKIPBP"` and `--extra ".IC V(VX)=2.5 V(VY)=2.5"` added | 1 s, `.IC` at 2.5 V | 71 s |
| D | `python tools/run_sim.py circuits/lia_baseline.cir --name P01_D_edges --analysis ".TRAN 0 10m 6m 10n SKIPBP" --extra ".IC V(VX)=2.5 V(VY)=2.5" --extra ".OPTIONS NUMDGT=8" --probe "V(VX_DEMOD)" "V(VY_DEMOD)" "V(N00261)" "V(N01577)" "V(N00890)" "V(N00695)" "V(N01681)"` | 10 ms, saved from 6 ms, 10 ns maximum step | 273 s |

Run D is an edge measurement. It is not a settling run. Run D also used `--timeout 3600 --wait 7200`, because it waited for another sweep to finish. Data files: `sim-runs/P01_A_2s_from0/P01_A_2s_from0.csd`, `sim-runs/P01_B_1s_ic/P01_B_1s_ic.csd` and `sim-runs/P01_D_edges/P01_D_edges.csd` (52 MB, 400110 points).

The circuit is `circuits/lia_baseline.cir` with A = 2 V, p = 0 deg and ost = 0 V. The runs were not repeated for this summary. PSpice was not run for this summary.

## Method

The settled values are the mean of VX and VY over the last 50 whole periods. At 517 Hz, one period is T = 1.934236 ms. The window is 96.71 ms long. The end times, 2.0 s and 1.0 s, are whole numbers of periods (1034 and 517), so the window starts at a period boundary of the reference.

The raw CSDF points are interpolated linearly onto a uniform grid of 96713 points with a spacing of 1.000001 us. The mean is the trapezoidal mean on this grid. The same method gives the mean over the 50 periods before the last window, which is the settling check.

The amplitudes of the 1f, 2f and 3f components come from a least-squares fit on the same grid. The ripple is the peak-to-peak value of VX on the grid.

The edge analysis for run D is in `docs/sim-results/scripts/P-01_edges.py`. It finds each reference edge, the instant the switch output changes, and the step, 50 % time and slew of the demodulator output.

The theory values come from the formulas in `docs/simulation-index.md`. The script `docs/sim-results/scripts/P-01_settling.py` runs the settled-value steps and prints every number of the settled table. Run it from the project root:

`python docs/sim-results/scripts/P-01_settling.py`

The edge script runs the same way, with `python docs/sim-results/scripts/P-01_edges.py`. It also writes `docs/sim-results/plots/P-01_y_edge.png`.

### Effective delay of the Y switching

The Y demodulator output moves through a 4.0 V step at a fixed slew rate. The full step lasts D = 4.0005 V / 20.19 V/us = 198.2 ns. A linear ramp of duration D has its centroid at D/2 = 99.1 ns. The effect of the ramp on the mean equals an ideal step delayed by 99.1 ns.

| Edge | Nominal instant | SEL 2.5 V crossing | Switch change | Slew delay (D/2) | Effective delay |
|---|---|---|---|---|---|
| Rising | rise start (TD) | +50.0 ns | +13.9 ns | +99.1 ns | 163.0 ns |
| Falling | TD + T/2 | +150.0 ns | +57.3 ns | +99.1 ns | 306.4 ns |
| Mean | | | | | 234.7 ns |

The mean effective delay of 234.7 ns is the value to compare with the Y delay inferred from the settled means. Taken from run A alone, the measured VY gives an effective delay of 238 ns. Taken from run B alone, it gives 235 ns.

A common delay in the Y reference shifts VY by K omega x delay, where K omega = 1.273240 V x 3248.67 rad/s = 4.136 mV/us. For 234.7 ns, this gives +0.971 mV.

## Discussion

### Run A and run B agree after the `.IC` tail is removed

The `.IC` start puts VX at 2.5 V. The settled value is 1.2268 V. The starting offset is therefore 1.2732 V. The filter time constant is 0.1 s, so the tail decays as 1.2732 V x exp(-t / 0.1 s).

The last-50-period mean of run B carries a bias from this tail. The bias is 1.2732 V x (0.1 s / 96.71 ms) x (exp(-9.033) - exp(-10)) = 0.097 mV on VX. It scales with |V - 2.5 V|, so a 1.2 s run gives a bias near 0.01 mV. The bias for VX is 0.097 mV. The estimate of the previous window is 0.257 mV, which gives the measured difference of 0.160 mV between the two windows. The VY bias is below 0.001 mV.

After this correction, run B gives VX = 1.227321 V - 0.097 mV = 1.227224 V. This equals run A to within 0.001 mV. Run A starts at 0 V, and its tail is below 10^-8 V at 1.9 s.

The index now recommends a 1.2 s run when 0.1 mV matters. Run B at 1 s is within the 0.1 mV pass criterion, but the margin is small, and the correction above is needed to see the true agreement.

### The VY deviation is explained by the Y switching delay

The run D edges give a mean effective delay of 234.7 ns for the Y switching. This delay is the sum of the SEL threshold timing (50 ns and 150 ns from the reference edges), the switch change (13.9 ns and 57.3 ns), and the slew of the demodulator output (99.1 ns on each edge).

The delay inferred from the settled VY is 238 ns in run A and 235 ns in run B. The run D edges predict 234.7 ns. The difference from run A is 3 ns. The predicted shift of +0.971 mV matches the measured +0.985 mV of run A and the measured +0.971 mV of run B.

The slew-limited output is therefore the main cause of the VY deviation. The VY deviation is explained within 0.014 mV, about 1 % of the deviation.

### Why X does not suffer the slew

The X edges sit at the zero crossings of the input sine, where the input is 2.5 V. The demodulator step is 4 sin(omega t), which is 9 to 17 mV in run D. The X slew delay is only a few tens of nanoseconds, because the step is small. The first-order effect on the mean is proportional to sin(omega t) at the edge, which is near zero. The slew of X is therefore second order, far below 0.001 mV.

The Y edges sit near the input peaks, where sin is about 1. The step is then about 4 V, and the slew delay is first order in the VY mean.

### The VX deviation is not explained

The VX deviation of +0.463 mV is not explained by any mechanism tested here.

The switch timing cannot explain it. A shift of X edges changes VX only to second order. The change is K (1 - cos(omega d)), which is 0.0001 mV for d = 0.24 us.

The op amp offset cannot explain it. The offset parameter of the OPAx192 model is -2.88 uV in `vendor/sbom862f/opax192.lib`. The unit and meaning of this value are not verified in the vendor notes. The closed-loop gain of 2 gives an output offset of about 6 uV.

Charge injection (QINJ = 0.4 pC into CD = 6 pF) makes a spike of about 67 mV that decays through RON = 120 Ohm in about 0.7 ns. It should give no net DC error. This argument is not checked by a simulation.

The VX_DEMOD ringing after the X edges is a possible contributor. The 90 % points reach 760 ns, and the steps are 9 to 17 mV. The mean of a ringing error is bounded by its peak times its duration divided by the period. This bound is about 17 mV x 0.8 us / 1.934 ms = 0.007 mV per edge. The ringing is therefore too small to explain 0.46 mV, unless it is not zero-mean.

The best reading is a small loss of gain in the X demodulator. VX minus 2.5 V is 0.036 % smaller than K. A gain loss of this size would not show on VY, where the gain term multiplies a value of 4 mV. The open-loop gain of the OPAx192 model is not stated in its file, so this reading is not verified.

### Earlier switching-delay estimate is superseded

The earlier estimate in this summary used switch thresholds of 1.8 V and 1.0 V. Those thresholds were wrong. The model switches at node voltages of 0.4 V and 0.7 V, which correspond to SEL of 1.32 V and 1.56 V. The delay estimate of 138 ns and the shift of +0.571 mV from that estimate are replaced by the measured values above.

## Design notes for the user

(a) The Y and X reference edges have a high time of T/2 + t_slope, because PSpice counts PW from the end of the rise. This adds 100 ns to the high time and shifts the mean reference edge by 100 ns. The duty cycle can be corrected with `PW = {0.5/f_osc - t_slope}`. The falling 50 % point then falls 50 ns after T/2, the same offset as the rising edge.

(b) The Y demodulator is slew-limited at its edges, because the Y reference switches near the input peaks. The step is about 4 V at A = 2 V, and the slew of the OPAx192 model is 20.19 V/us. This costs about 0.4 mV of VY at A = 2 V, from the 99 ns slew delay. The cost scales with the square of the amplitude, because the step scales with A and the slew delay scales with A. At A = 1 V, the cost is about 0.1 mV. A faster Y demodulator, or a lower step size in the Y path, reduces it.

## Open points

1. The VX deviation of +0.463 mV (+0.038 %) is not explained. The best reading is a gain loss of 0.036 % in the X demodulator. The VX_DEMOD ringing is a possible contributor, but its bound is only 0.007 mV per edge.
2. A run with A = 0 V separates an offset from a gain error. With no input, VX and VY should both equal 2.5 V. A gain error gives 2.5 V exactly, while an offset gives a constant shift. A run with A = 1 V gives the scaling of the error with amplitude.
3. The open-loop gain of the OPAx192 model is not stated in its file. The offset value of -2.88 uV is not checked against a unit.
4. The dispatcher's VY point value claim (about 1.2 mV below theory) does not hold for the settled mean. The quirks file was not changed.
