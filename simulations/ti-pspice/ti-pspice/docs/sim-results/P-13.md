# P-13 Op amp offset

## Goal

Confirm that an offset at the non-inverting input of the demodulator op amp appears doubled at the output.

## Method

**Settled window.** The window is the last 20 whole periods of 517 Hz. It has a length of 38.6847 ms and runs from 111.3153 ms to 150.0000 ms. The settling factor for tau = 10 kOhm x 1 uF = 10 ms is F = 3.706e-6.

**Mean and settling.** The mean is the time-weighted trapezoid mean over the raw points, with interpolated ends. The settling bias is removed with V_ss = (m - 2.5 V x F) / (1 - F). The window of the same length before the last one is the settling check. It runs from 72.6306 ms to 111.3153 ms.

**Sign from the netlist.** The netlist has the line `V_VOSX N00695 N00695P {vos}`. In SPICE, a voltage source `V name n+ n- value` sets V(n+) - V(n-) = value. So V(N00695) - V(N00695P) = vos, and the op amp input N00695P sits at V(N00695) - vos. N00695 is the switch output (REF in the -1 state, N00890 in the +1 state). With R1 = R2 = 10 kOhm the output of U2 is

V_out = (1 + R1/R2) V+ - (R1/R2) V(N00890) = 2 V_sw - V(N00890) - 2 vos.

The shift is -2 vos in both switch states. U4 has the same line for the Y channel (`V_VOSY N01681 N01681P {vos}`), so its shift is also -2 vos. At rser = 1 mOhm the offset also changes the node current by about vos / R2, and the node moves by about eps x vos. This is 1e-7 x 25 uV, which is negligible.

**Model offset at vos = 0.** The residual of the measured vos = 0 values is taken against two theories. VX is compared with the ideal value 2.5 V - 2A/pi. VY is compared with the P-08 model (0.18 deg Y timing error, 126 ns constant lag and the slew term, see `docs/sim-results/P-08.md`). The residual is also given as an equivalent input offset, which is residual / (-2).

The slope between the two steps is dV/dvos = -1.99983 for VX and -1.99458 for VY. The even part, (dV(+25) + dV(-25)) / 2, is -0.010 uV for VX and +0.018 uV for VY.

## Discussion

**Sign.** The netlist gives V(N00695) - V(N00695P) = vos. So the op amp input sits at the switch output minus vos, and the output shifts by -2 vos. The data confirm this. A vos of +25 uV gives -50 uV in both channels. The entry says +2 vos. The entry's formula, (1 + R1/R2)(V+ + vos) - (R1/R2) Vin, uses the other sign. For the netlist as written, it should read (V+ - vos). The magnitude is correct, so the doubling holds. The sign differs only by the source orientation. Either the entry's convention or the netlist orientation should change. The judge should choose which. This analysis changed neither the netlist nor the entry. If the intended meaning is "vos adds to IN+", the nodes of `V_VOSX` and `V_VOSY` would need to be swapped in the circuit file. This is a circuit change, and it was not made here.

**Magnitude.** The shifts are within 0.16 uV of 2 vos for all four readings. The VX slope is -1.99983, and the VY slope is -1.99458. The VY slope is 0.27 % low, which is about 0.15 uV at 25 uV. The cause of this 0.15 uV difference is not identified. It is far below the 2 uV limit.

**Model offset.** The VX residual at vos = 0 is -0.89 uV. It is equivalent to a +0.45 uV input offset. The VY residual against the P-08 model is -3.95 uV. It is equivalent to a +1.98 uV input offset. That is close to the 2 uV limit. The VY residual against the ideal 0.18 deg theory is +52.7 uV. So the lag and slew terms of P-08 are needed. The P-08 constants come from a 20 us run, and P-08 flagged them as open (its open point 6). The VY offset at this amplitude depends on those constants, so the residual is only as good as the P-08 model.

The OPAx192 model contains an internal offset block with DC = -2.88 uV (`vendor/README.md`, not verified against the datasheet). Its node was not traced in this analysis. If it sat at the input of both op amps, it would shift each output by about -5.8 uV, which the VX residual does not show. So the block is not the whole explanation, and this is not verified.

**Design values.** `docs/design-context.md` section 4 gives the expected DC offset at the demodulator input as TBD. No design limit exists for this offset. The 2 uV pass limit comes from the entry only. The entry's Vampl of 0.2 V is close to the Draft input level of about 166 mV (`docs/design-context.md` section 4), as design issue D-09 recommends.

## Open points

1. The entry's sign (+2 vos) does not match the netlist orientation (-2 vos, from `V_VOSX N00695 N00695P {vos}`). The judge should decide whether to change the entry, the netlist, or both. No expected value was changed here.
2. The entry's formula, "(1 + R1/R2)(V+ + vos)", should read "(V+ - vos)" for the netlist as written. The same sign holds in both switch states.
3. The 2 uV pass limit has no design source. `docs/design-context.md` section 4 gives the offset at the demodulator input as TBD.
4. The VY slope is 0.27 % low (-1.99458 against -2). The 0.15 uV difference to VX is not explained.
5. The VY model offset of +1.98 uV (equivalent) relies on the P-08 constants, which were fitted at 20 us (P-08 open point 6). A refit at 5 us was not made.
6. The OPAx192 offset block (DC = -2.88 uV) was not traced to a node. Its role in the residual is not verified.
7. The entry names `circuits/lia_v3_fast.cir` with Vampl = 0.2 V. The run used `circuits/lia_v3_fast_P10a0.cir`, which has vampl = 0.2 V (see P-12 open point 3). The entry should cite the copy. This was not changed.
8. The exact command line is not in a log. It is rebuilt from `sim-runs/P13_vos/P13_vos.cir` (not verified).
9. The P-08 summary gives its prior window as 91.6306 ms to 111.3153 ms (19.68 ms). The P-08 script uses 72.6306 ms to 111.3153 ms, the same length as the window. This summary uses the latter (see P-12 open point 9).
