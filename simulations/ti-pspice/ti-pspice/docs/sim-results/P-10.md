# P-10 Coherent pickup on the reference and the rail

## Goal

Measure the DC error from a ripple at f_osc on Vref, on the 5 V rail, and from an excitation current that loads the rail (D-04).

## Runs

All runs use the fast settings of `docs/simulation-index.md` (Vampl = 0.2 V, ost = 0, p = 0, cout = 1 uF, tau = 10 ms). Each run folder holds the circuit as run (`<run>.cir`), the text results (`<run>.csd`) and the log (`<run>.out`). Every run ended with status `done`. The logs show only the known warnings ORPSIM-15256, ORPSIM-15459 and ORPSIM-16534. The run command had this form:

```
python tools/run_sim.py circuits/lia_v3_fast_<copy>.cir --name <run> --analysis ".TRAN 0 0.15 0 5u SKIPBP" --analysis ".STEP PARAM <x> LIST <values>" --extra ".OPTIONS NUMDGT=8" --extra ".IC V(VX)=2.5 V(VY)=2.5" --probe "V(VX)" "V(VY)" "V(REF)" "V(VDC)"
```

## Method

- **Settled window.** The last 20 whole periods of 517 Hz, from 111.3153 ms to 150.0000 ms (38.6847 ms). This is the window of the fast settings. The common rule of 50 periods applies to the default settings only.
- **Means.** Time-weighted trapezoid means of the PSpice points, with the window ends interpolated. The point mean is not used, because the adaptive step biases it (`docs/simulation-quirks.md`).
- **Settling check.** The last window minus the window of the same length before it (72.6306 ms to 111.3153 ms). The settling bias of VX and VY is `B = dprior / (1 - exp(TW / tau))`, and the corrected mean follows the P-08 formula. The correction is below 0.5 uV in every run.
- **Readout.** VX and VY minus the mean of V(REF) in the same window, as the entry defines it. Deltas are each step minus step 0 of the same run.
- **Ripple.** Least-squares fit of the 1f and 2f sinusoids on a 0.5 us grid. Used for the reference and rail ripple only.
- **Pass criterion.** The entry's criterion: the difference must be within the larger of 0.01 mV and 3 % of the expected value.
- **Y timing.** The Y reference (V_V6) is high from 482.6 us. The entry assumes T/4 = 483.56 us. The overlap with the rail droop and the Y ripple phase were calculated from this delay, and the results are compared below.

## Discussion

**Readout and reference (P10a, P10c).** The reference ripple gives the expected readout. A 1 mV ripple at pref = 0 gives dVXr = +0.6366 mV. At pref = 90 deg it gives dVYr = -0.6363 mV. The ripple on a half-scale reference (kref = 1) gives half of the response, 0.3183 mV. These values follow the 2a/pi rule of the entry. The small residuals (0.0015 mV for P10a0, dVYr) come from the Y timing. With the Y reference high from 482.6 us, the ripple is weighted by cos(2 pi f t_s). The formula (2a/pi) cos(2 pi f t_s) gives 0.0020 mV, against 0.0015 mV measured. The sign and order agree. The 0.0005 mV difference is not explained (not verified).

**Rail ripple (P10b, P10c).** With the reference ideal (kref = 0), a 1 mV rail ripple changes VY by 0.26 uV and VX by 0.01 uV. The rail coupling through the op amps is therefore 72 dB below the ripple for VY, and about 100 dB below it for VX. With kref = 1 the reference carries the rail ripple at half amplitude, and the readout changes by 0.3183 mV in VX. The entry expects this value, so the rail ripple reaches the readout only through the reference.

**Excitation current (P10d, P10e).** The 10 mA current from the rail drops VDC by 10.00 mV during the first half period, and the drop is 9.998 mV in the half-period difference. With the reference ideal (P10d), the readout barely moves. VY changes by 0.17 uV, which is -95 dB relative to the drop. With the reference buffered from the rail (P10e), the reference falls by 2.5 mV in the mean. The readout falls by 2.50 mV in VX, as the entry expects. The absolute change in VY is -2.506 mV, which is 0.006 mV more than the entry's -2.500 mV.

**The -2.506 mV in VY (dispatcher note 1).** The Y reference is high from 482.6 us, not from T/4 (483.56 us). The Y low window therefore overlaps the first-half rail droop for (T/2 - 482.6 us) / T = 25.050 % of the period, not 25.000 %. The predicted absolute shift is -2.5050 mV with the droop ending at T/2, and -2.5055 mV with the droop ending 100 ns later. The measured value is -2.5058 mV. The Y timing explains all but 0.0003 mV to 0.0008 mV. The readout shift is then -0.0050 mV, against -0.0055 mV measured. The entry expects zero here.

**Baseline shift of P10e (dispatcher note 1).** With rrail = 1 Ohm, the circuit's own supply current flows through the rail resistance. The VDC baseline falls by 2.0095 mV in P10d and P10e against P10a0. This gives an inferred quiescent current of 2.01 mA through 1 Ohm. The reference falls by 1.006 mV, and the absolute VX and VY fall by about 1.0 mV. The readout, VX minus the mean of V(REF), changes by only 1.7 uV, so the sag does not reach the readout. The 2.01 mA value is inferred from the sag. It is not checked against the OPAx192 model (not verified).

**Settling.** The window correction is below 0.5 uV in every run, and every expected difference is far above that. The settling check does not limit the result.

**Design values.** The entry's test values, 1 Ohm and 10 mA, are marked TBD in `docs/design-context.md` section 1. The design context gives the excitation drive as a Draft value and the rail as 0 V to 5 V (Current). The results apply to the test values only. The design context also gives the demodulator input as about 166 mV (Draft). The entry uses 0.2 V. The P-10 deltas come from the reference and the rail, not from the signal. The 0.2 V choice is therefore not expected to change them. This was not checked at 0.166 V.

## Open points

1. **P10e expected VY values.** The entry expects an absolute VY shift of -2.500 mV and a readout shift of 0. The Y timing gives -2.505 mV and -0.005 mV. The entry should use the Y reference delay of 482.6 us. This is a proposal for the judge and the user. The expected values were not changed.
2. **Pass criterion versus "below 0.005 mV".** The entry gives a 0.01 mV criterion and also a 0.005 mV statement for P10b and P10d. Both pass here. The entry should state one criterion.
3. **Pulse width of the drives.** The `PULSE` sources V_V2, V_V6 and I_IEXC measure their width from the end of the rise. The high time is T/2 + t_slope, not T/2. This gives the 100 ns reference duty offset found in `docs/sim-results/P-11.md`. It also lengthens the iexc window by about 100 ns. The size of this effect on the P-10 results was not checked. The fix belongs to the schematic, and the user should make it in Capture.
4. **The VY residual of P10a0.** The predicted Y timing residual is 0.0020 mV and the measured one is 0.0015 mV. The 0.0005 mV difference is not explained.
5. **Quiescent current.** The 2.01 mA value comes from the rail sag, not from the op amp model. The model's `IQ_SRC` value was not checked.
6. **Rail coupling mechanism.** The VY coupling in P10b (0.26 mV per V of rail ripple) is not traced to a model element. The op amp PSRR and the switch model were not examined (not verified).
7. **D-04.** The entry cites D-04 for this test. `docs/design-issues.md` was not read for this analysis, so the link to D-04 is not verified.
