# P-24 Front-end AC response with vendor models

## Goal

Measure the in-amp and K = 2 band-pass response of the LIA-AFE-Eval board with the INA828 and OPAx196 models, and the extra gain and phase error of the finite amplifier bandwidth.

The first P24b attempt failed with status error (floating nodes RGP and RGN, see `docs/simulation-quirks.md`). The copy `circuits/afe_eval_P24b.cir` therefore has R_R10 commented out, in addition to the three block replacements of the entry. Its header gives the run command. No run has an `ERROR` line in its final `.out`. Both runs show the usual `WARNING(ORPSIM-15459)` on the pulse sources and `WARNING(ORPSIM-16534)`, which are harmless here.

The analysis script is `docs/sim-results/scripts/P-24_ac.py`. Run it from `simulations/ti-pspice` with `python docs/sim-results/scripts/P-24_ac.py`. It writes the plot `docs/sim-results/plots/P-24_front_end.png`.

## Method

**Transfer functions.** Each stage is the ratio of the probed nodes, with the drain difference as the input:

- INA828 stage: V(INA_OUT) / (V(DRN_B) - V(DRN_A)).
- High-pass stage (U3A): V(HPF_OUT) / V(INA_OUT).
- Low-pass stage (U3B): V(BPF_OUT) / V(HPF_OUT).
- Front end: V(BPF_OUT) / (V(DRN_B) - V(DRN_A)).

The excitation amplitude does not enter the ratios, so acexc = 1 is a convenient linear scale. The AC response is complex and was read with `tools/csdf.py`.

**Ideal reference.** The ideal values are the closed forms of `docs/sim-results/scripts/afe_eval_expected.py` (functions `hpf`, `lpf`, `front`, and G_INA = 1 + 50 kOhm / 5.62 kOhm = 9.896797 V/V). The script evaluates them at the same grid frequencies as the run. The grid is logarithmic with 200 points per decade, so the points are 517.571 Hz, 1032.69 Hz, 1545.15 Hz and 5000.00 Hz, not 518 Hz, 1036 Hz and 1554 Hz. Pass or fail is therefore decided on the same grid point. The entry's nominal frequencies are quoted in the tables for reference only.

**Peak and band.** The peak is the grid maximum. The -3 dB edges are found by log-frequency interpolation between the grid points on each side of the peak. The same routine is applied to the run and to the ideal curve.

**Phase slope.** The slope at 518 Hz is the phase difference over the two grid points on either side of 517.571 Hz, divided by their frequency difference (11.9 Hz). It is computed for both curves.

**Settling.** Not applicable. This is an AC analysis with no time dependence.

**GBW estimate (estimate, not a simulation).** The phase and gain deficit of each OPAx196 stage at 517.571 Hz is scaled by nominal GBW / GBW, that is by 1 / 0.7 for -30 % and by 1 / 1.3 for +30 %. The INA828 deficit is not scaled, because its internal amplifiers are not the OPAx196 model. This is a first-order scaling of the phase of a single-pole amplifier, so it is an estimate.

## Discussion

**Wiring.** The ideal-block copy reproduces the closed form to better than 0.0002 % in gain and 0.00003 deg in phase at every checked point, so the netlist of the K = 2 band-pass and the INA828 gain (1 + 50 kOhm / 5.62 kOhm) are wired as the expected script assumes. This is the wiring check the entry asks for. It is the only pass or fail criterion of P-24 that the entry gives.

**Vendor models.** The vendor-model front end at 517.571 Hz reads -0.024 % in gain and -0.18 deg in phase. The INA828 model gives +0.0002 % and -0.06 deg. The two K = 2 stages give -0.117 deg in total phase (-0.055 deg and -0.062 deg). The op amp bandwidth alone is a small part of the phase error at 518 Hz, because the GBW estimate changes the phase by at most 0.05 deg for a 30 % change of GBW. The INA828 model contributes the same order of phase error, and it is not scaled by GBW. No temperature was simulated, so this run says nothing about the temperature dependence.

**Smoke run.** The smoke run of 7 November 2026 gave -1.53 deg and -0.167 % against the ideal chain at 518 Hz. The table below splits this difference into contributions. The front-end value is from this entry. The cmux value is a hand estimate with the values given in the table.

| Contribution | Phase (deg) | Gain (%) | Source |
|---|---|---|---|
| Smoke run against ideal chain | -1.53 | -0.167 | smoke run, 7 November 2026 |
| Front end, vendor models | -0.177 | -0.024 | P-24 (this entry) |
| 10 pF cmux on the drain nodes (60 pF total, lag 3.687 deg instead of 3.07 deg, amplitude 0.99793 instead of 0.99858) | -0.617 | -0.065 | hand estimate, not verified |
| Not yet explained | -0.74 | -0.078 | remainder |

The remainder of about -0.74 deg and -0.078 % lies in the excitation or drain part of the chain. P-27, which has a judge note on this point, is where to locate it.

**Entry arithmetic.** The entry gives the transfer of the front end and its phase slope, which agree with the closed form. The entry value of the drain-to-BPF phase (168.67 deg) includes three terms that the expected script does not compute (171.73 deg, -3.07 deg and +0.01 deg). They were not checked in this entry.

## Open points

1. The entry's wiring check P24b needs R_R10 to be removed from the copy, because the RG nodes float when X_U2 is replaced. The index entry should mention this step. The entry was not changed.
2. The entry's nominal frequencies (518 Hz, 1036 Hz, 1554 Hz) are not on the decade grid. A run with `.AC LIN` at these frequencies would test them exactly. The present comparison uses the same grid point for both curves, and the entry values differ from the run points by up to -8.85 Hz.
3. The remaining -0.74 deg and -0.078 % of the smoke run are not explained. They are not the front end (-0.177 deg and -0.024 %) and not the cmux estimate (-0.617 deg and -0.065 %). P-27 should locate them. The entry's phase constant of 168.67 deg has three terms that are not verified here.
4. The GBW estimate is a scaling estimate. A true measurement would need an OPAx196 model with a scaled GBW, which the vendor library does not provide as a parameter. The estimate has not been checked by simulation.
5. The INA828 model is not part of the GBW estimate. Its contribution (-0.059 deg) is not scaled, and its internal temperature dependence is not simulated.
6. The expected values of the entry use the schematic values (RG = 5.62 kOhm, all capacitors 33 nF, all resistors 9.31 kOhm and 10 kOhm). No design-context value is quoted in this entry, so no conflict was found with `simulations/design-context.md` for these values.
7. The cause of the vendor stop-band error above about 10 kHz (gain +89.8 % and phase -65.2 deg at 20.14 kHz) is a hypothesis (feedthrough through C9 with finite loop gain). It is not verified. It matters for the harmonic and interference entries, not for the 518 Hz result.
