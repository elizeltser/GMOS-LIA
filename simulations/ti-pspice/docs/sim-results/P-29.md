# P-29 System CMRR with node capacitance

## Goal

Find the leakage of a common-mode drain signal into X and Y from the R_D and node-capacitance mismatch. This is SIM-12 of the board. The median system CMRR must be at least 48 dB, and the leakage is reported in X and Y.

## Method

**Circuit.** Both drains sit at 0.1575 V DC (2.6325 V through 330 kOhm, with 7.5 uA sinks). One common AC current of 1/330 kOhm A enters each drain in phase. Each drain has R_D (`RD` model, 0.1 % uniform), 50 pF pixel capacitance (`CN` model, 10 % uniform), and a fixed 10 pF on-capacitance of the mux. The INA828 vendor model adds its own input capacitances. The mux path is ideal (no series resistance). The front end is the vendor INA828 with RG = 5.62 kOhm, followed by the K = 2 band-pass with OPAx196, with nominal components.

**CMRR.** Per pass, CMRR = |(V_A + V_B) / 2| / |V_B - V_A|, taken from the drain probes. The cross-check uses BPF_OUT. The nominal BPF_OUT contains the vendor INA828 common-mode leakage. It is subtracted, and the rest is divided by 39.578 V/V (P-27 vendor gain).

**Nominal differential.** The nominal drains are equal, so V_B - V_A is exactly zero. The nominal BPF_OUT (45.56 uV at -155.53 deg) is therefore the INA828 common-mode leakage only. It is not a differential reference. The conversion of BPF_OUT to the differential drain signal is done per pass instead.

**Phase split.** The reference is the differential drain phase per unit in-phase sink current on side A. P-27 gives (DRN_B - DRN_A) / GATE = -4.427 deg with G_PIXA already a sink, so the wanted reference is phi_w = -4.427 deg. The nodal model with 70 pF and 1 pF coupling gives -4.422 deg, which agrees. For each pass, eps = (V_B - V_A) e^(-j phi_w) / |cm|, with |cm| the common-mode drain amplitude. X is the real part (on the wanted axis) and Y the imaginary part (quadrature), in percent of |cm|.

The drain stage has its own lag of about 4.4 deg. Each mismatch therefore lands about 4.3 deg off its nominal axis. The R_D mismatch lies mainly on the wanted axis, and the C mismatch lies mainly in quadrature. A part of each mismatch leaks onto the other axis, with the sine of the offset as the fraction. This is the reason for the X leakage below.

**Expected values.** The entry model (50 pF toleranced, no fixed capacitance) gives a median of 49.8 dB. The corrected board model adds 20 pF matched fixed capacitance (10 pF mux and 10 pF INA828) and 1 pF coupling. It gives 49.7 dB. The numpy runs use 200 000 samples. Both use the same uniform tolerances as the PSpice run.

**Settling.** Not applicable. The run is a single-frequency AC analysis.

## Discussion

**Median and spread.** The median CMRR is 49.3 dB. It is 0.4 dB below the corrected numpy value. The bootstrap standard error of the median is 0.56 dB, so the difference is within one standard error. The 5 % and 95 % points agree with numpy to 0.15 dB and 0.7 dB. The 95 % point is slightly higher than numpy, which is consistent with 199 samples.

**Why the 20 pF fixed capacitance does not change the median.** A matched fixed capacitance adds the same susceptance to both drains. It does not change the mismatch, and the mismatch is what leaks. The entry model and the corrected model differ by 0.1 dB in the numpy runs. The 20 pF and the 1 pF coupling change the drain amplitude and the phase of the wanted signal, not the CMRR. The matched C cases give 64.7 dB in both models. This is the same as the entry value of 64.6 dB.

**Arithmetic check of the leakage.** For a drain with R = 330 kOhm and C = 50 pF, the mismatch gives a differential of about omega R dC relative to the common-mode amplitude. With omega = 2 pi 518 Hz = 3254 rad/s, omega R = 1.074 x 10^9 1/F. A 10 % uniform tolerance on 50 pF has a standard deviation of 2.887 pF per node. The difference of two nodes has 4.08 pF. Then omega R x 4.08 pF = 0.438 %, which is the predicted C-mismatch amplitude on the drain axis. The measured Y standard deviation is 0.4452 % (1.6 % apart, within the uncertainty of 199 samples).

**X prediction.** The C mismatch lies 4.3 deg off the quadrature axis (the sine of 4.3 deg is 0.075). So about 7.5 % of its amplitude, 0.438 % x 0.075 = 0.033 % of |cm|, appears in X. The R_D mismatch gives 0.0816 % (0.1 % uniform on each resistor, difference of two). The X standard deviation is then sqrt(0.0816^2 + 0.033^2) = 0.088 %. The numpy value is 0.0875 % and the PSpice value is 0.0814 %. The PSpice value is 7 % below the prediction. With 199 samples the standard error of a standard deviation is about 5 %, so the difference is 1.6 standard errors and is not significant.

**Split of the leakage.** About 97 % of the leakage power goes into Y (96.8 % PSpice, 96.1 % numpy). The C mismatch dominates. The X part is about 0.08 % of the common-mode amplitude, and most of it is C mismatch leaking through the 4.3 deg offset of the drain lag, not R_D mismatch. The entry statement that the capacitance part goes mainly into Y is therefore confirmed. The entry statement does not say that the R_D part is in X. The R_D part is small in both axes.

**Vendor INA828 leakage.** The vendor INA828 model adds a common-mode leakage of 118.75 dB at the nominal drains (using the nominal |cm| of 0.997183 V). This is well above the drain mismatch leakage of 49 dB, so the system CMRR is set by the drains. The value agrees with the INA828 CMRR of at least 100 dB quoted in the entry.

**Amplitude.** The CMRR is a ratio of linear quantities, so the 1 V per 330 kOhm common-mode amplitude does not change the result. The SIM-12 description in `simulations/simulation-plan.md` uses a 300 mVpp common-mode drive. The same CMRR follows from that drive.

## Open points

1. **Node capacitance definition.** `simulations/simulation-plan.md` (SIM-12) describes C_node = 50 pF ±10 % as mux on-capacitance plus INA input plus traces. `simulations/design-context.md` (drain path row) says "drain node capacitance about 50 pF ±10 %" without a breakdown. The corrected model adds 20 pF on top of the toleranced 50 pF. If the 50 pF already includes the mux and INA inputs, the total is 50 pF and the CMRR is unchanged (the mismatch is the same 10 % of 50 pF). The two documents do not state the same thing. The analyst does not choose. The owner should decide which reading is correct.
2. **Mux capacitance tolerance.** The 10 pF TMUX1109 on-capacitance is fixed and matched in the model. If it has a 10 % tolerance, the Y standard deviation rises by about 2 % (from 4.08 pF to 4.16 pF on the difference). The median CMRR falls by about 0.2 dB. This is not run. The value (10 pF) is an assumption of `circuits/afe_eval.cir`, not verified against a datasheet.
3. **Matched C case.** The entry lists a matched-C median of 64.6 dB. The run with matched C was not made. The numpy value (64.7 dB) covers it.
4. **Sample count.** The `.MC 200` run gives 200 runs in total, the nominal and 199 random samples. The statistics use the 199 samples. The entry's `.MC 200` is therefore 199 samples, not 200.
5. **Drain resistor tolerance.** The R_D tolerance of 0.1 % is the value of the entry and of `design-context.md`. The statistical spread of the leakage follows directly from it. Not verified against a supplier tolerance.
6. **Index target.** The 48 dB target is the SIM-12 target of `simulations/simulation-plan.md`. It is not in `design-context.md`, so the design context does not confirm it.
7. **Phase reference.** The reference uses the P-27 value of -4.427 deg, which includes the feedthrough to DRN_B. The nodal value is -4.422 deg. The difference (0.005 deg) is not used.
