## Method

**Circuit state.** The circuit is `circuits/afe_eval.cir` at its defaults. The bench inputs are v5 = v5n = 5.3 V (the circuit default, not the 5.0 V of the entry), v15 = 15 V, vgdac = 1.0 V, vdrc_a = vdrc_b = 2.4 V, ida = idb = 7.5 uA, heaters off in P23a and P23d. P23b sets DAC1 to 1.25 V and 2.0 V, so the heater A output is 2.5 V and 4.0 V.

**The vda state.** The entry asks for `.STEP PARAM vda LIST 0` in P23a, so the drain AC term is zero there. P23b and P23c keep the default vda = 10 mV. The drain and in-amp checks use P23a only. The heater checks use P23b. The sweep uses the default vda.

**Bias values.** Every node voltage comes from the "SMALL SIGNAL BIAS SOLUTION" table of the `.out` file, with `.OPTIONS NUMDGT=8`. The parser keeps top-level node names, and the internal model nodes (for example `X_U26B.MID`) when the settling check needs them.

**Closed-form values.** The expected values come from the ideal relations of the entry:

- GATE = (1 + R5/R6) x 1.0 V - (R5/R6) x 1.65 V = 0.994583 V. The entry rounds this to 0.99458 V.
- VSUP_A = 1.1 x 2.4 V - 1 kOhm x 7.5 uA = 2.6325 V.
- DRN_A and DRN_B = VSUP_A - 330 kOhm x 7.5 uA = 0.1575 V.
- HFB_A = 2 x DAC1.
- Heater current I_htr = HPIX_A / 600 Ohm. The path is 4.5 Ohm (U20) plus 600 Ohm.
- Shunt current = I_htr + I_bleed, where I_bleed = HFB_A / 99.8 kOhm is the R20 and R22 feedback divider. The shunt drop 15 Ohm x shunt current is added to HFB_A.

**Settling check.** A `.OP` is a pseudo-transient in PSpice. It stops when the residual of the solver is below the `PTRAN` tolerances in `options.inc`. Slow nodes may not be settled at that point, so the check tests the bias point directly. The post-filter node and the op amp MID nodes are checked here. The other slow nodes are checked in the settling table of the Results:

- Node NC13 of the post-filter. Capacitor C13 is open at DC, so the current in R14 must equal the current in R15. The residue is I(R14) - I(R15), with I(R14) = (X_DEM - NC13) / 200 kOhm and I(R15) = (NC13 - U26BP) / 200 kOhm. The limit is 1 pA.
- The internal MID node of each OPAx196 model. It must sit at (V+ + V-)/2 of its own rails. The limit is 10 uV. Twelve op amps are checked (U1A, U1B, U3A, U3B, U9A, U9B, U10A, U10B, U26A, U26B, U27A, U27B).

The check fails for every bias point printed in this run, as the table in the Results shows. The X_OUT and Y_OUT values of the bias tables, and the P23c sweep curve, are pseudo-transient values, not settled DC values. They are not used for the pass. P23e did not converge (see Results), so the settled values are given analytically.

**Rail margin.** The margin of a pin is the smaller of its distances to V+ and V-. The rails are P5VA and M5VA for all stages except U9A and U9B, which run from P5VP and M5VA. The INA828 uses P5VA and M5VA. The transition region of the OPA2196 input stage is V+ - 3 V to V+ - 1.5 V (the window of the entry).

**Diode voltage.** V_F(D5) = V(VIN5P1) - V(P5VIN). The current in D5 is the sum of the currents through R18 and R32, from the node voltages and the 1 Ohm rail resistors.

**ABSTOL and analysis-path check.** The entry uses the solver default from `options.inc` (ABSTOL = 1 nA). Single bias points were rerun with ABSTOL = 1 pA, and P23d repeats the stepped `.OP` with vda = 0 and vda = 10 mV. The check shows whether the solver tolerance or the analysis type changes X_OUT. Neither does.

**Probe limit of P23c.** P23c probed five nodes only: P5VA, P5VP, X_OUT, GATE and VSUP_A. The rail margins and the transition-region checks therefore come from the full bias tables of P23a and P23b. The sweep result at v5 = 4.6 V is argued from the probed rail and the constant bias nodes (see Results).

### Evidence for the cause

The following facts come from the bias tables and from the model file `OPAx196.LIB` (`C:\CDS_SPB_HOME\CDSSETUP\PSPTILIBDIR\`).

- (a) KCL at NC13 fails by 45 to 267 pA in all rows above.
- (b) The OPAx196 input bias current is I_B = 5.25 pA, I_OS = 2.75 pA, and R_DIFF = 100 MOhm (`I_I_B`, `I_I_OS`, `R_R_DIFF`). The input voltage difference of U26B is -16.848 uV, so the current through R_DIFF is 0.17 pA. The model input current is about 5 pA, not 756 pA.
- (c) In all twelve op amps the internal MID node sits 0.94 to 1.21 mV away from (V+ + V-)/2. The MID node is held by R48 and R50 (1 MOhm each) with C_C14 (1 uF). The MID offsets have no visible effect on the outputs, because the U26B input difference is 16.839 to 16.848 uV in every run. The time constant is about 0.5 s, so a pseudo-transient that stops early leaves it unsettled.
- (d) The cause is the `.OP` pseudo-transient, `.OPTIONS ADVCONV`, with the loose PTRAN tolerances of `options.inc` (PTRANABSTOL = 1e-5, PTRANVNTOL = 1e-4). ABSTOL does not control this stop. The residue depends on the path of the ramp: the vda term of the pixel stand-in is large while GATE ramps, and the heater ramp loads the rails. This explanation is inferred from (a) to (c), and it is not verified.
- (e) The expected settled DC value is derived in the next subsection.

### True DC value of X_OUT (analytic)

With the settled DC state, C13 and C15 are open, so the current in R14 and R15 is the input bias current of U26B (5.25 pA). The U26BP node is X_DEM minus 400 kOhm x 5.25 pA:

- U26BP = X_DEM - 400 kOhm x 5.25 pA = -67.07 uV - 2.10 uV = -69.2 uV.
- X_OUT = U26BP + 16.85 uV (the input offset of U26B, from the model difference) = about -52 uV = -0.052 mV.

The value is -0.052 mV in every state, because X_DEM is -0.067 mV in every run and the input current is the model value. The margin to the 0.5 mV limit is 0.45 mV. This value is analytic and is not simulated, because P23e did not converge.

### Bound on X_OUT from the offsets of the chain

At DC the expected X_OUT follows from the offsets of each stage, with the DC gain of each stage. The band-pass passes the offsets of U3A and U3B with gain 2 each, and only the INA828 offset is blocked by the high-pass. The argument of the judge gives

X_OUT = -4 Vos(U3A) - 2 Vos(U3B) + 2 Vos(U26A) + Vos(U26B) - 400 kOhm x I_B(U26B).

With the model offsets of about 16.85 uV each, this is -3 x 16.85 uV - 2.1 uV = -52.6 uV. This agrees with the analytic value of -52.3 uV within 0.3 uV, which is the rounding of the model values. The bias-table values of the chain agree with the gains: HPF_OUT is 33.63 uV (2 Vos of U3A) and BPF_OUT is 100.79 uV (about 2 x 33.6 uV from the high-pass plus 2 x 16.85 uV of U3B).

At datasheet maxima (Vos 100 uV per amplifier, from P-28, and I_B 20 pA, as quoted in P-28 and not read here), the worst case is 9 x 100 uV + 8 uV = 0.91 mV. The root-sum-square of the offsets is 5 x 100 uV = 0.50 mV, plus the current term. The 0.5 mV limit therefore holds for the model offsets only. It is not a guaranteed bound for the datasheet range.

The entry's bound "(2 Vos of U26A plus Vos of U26B)" omits the front-end chain of U3A and U3B, a term of 6 Vos. The entry is not changed here. The design reviewer should review this bound. The PASS for X_OUT rests on the analytic value with this argument.

### P-28 corroboration

`docs/sim-results/P-28.md` (section "Offset budget from the bias table of P28c") gives the zero-signal offset of a bias point with ideal symmetric rails. In that run the MID nodes sit at about 1e-20 V, so the bias point is settled. The reported values are U26BP = 31.025 uV, U26AM = 16.515 uV, X_OUT = 47.540 uV. The input current through R14 + R15 is 5.08 pA, inside the datasheet maximum of 20 pA (typical 5 pA, as read in P-28). This confirms the analytic size of the term: tens of uV from the input offsets and the input current, not 0.35 mV. The bias value of X_OUT in P-28 is not the same circuit as P-23 (P-28 uses symmetric rails and a different offset path), so it supports the order of magnitude only.

**Arithmetic check of the entry (entry not changed).** The entry gives U9A output = HFB_A + 15 Ohm x I_htr = 4.099 V at 4.0 V. With I_htr = 4.0 V / 604.5 Ohm = 6.6170 mA, the shunt drop is 99.255 mV, so the output is 4.09926 V. The R20 and R22 divider also draws 4.0 V / 99.8 kOhm = 40.08 uA through the shunt. That adds 15 Ohm x 40.08 uA = 0.601 mV, so the corrected output is 4.099857 V. The measured 4.099889 V agrees with the corrected value to 0.032 mV. The entry value 4.099 V is 0.86 mV low, inside the 1 mV limit. The entry's HSENSE_B value of 2.48 V has the same missing 0.6 % term. The corrected value at 2.0 V is 2.496420 V.

At DAC1 = 1.25 V the same arithmetic gives HFB_A + 15 Ohm x (I_htr + I_bleed) = 2.562410 V. The measured 2.562443 V agrees to 0.033 mV.

## Discussion

**Bias checks.** The DC levels of the front end, the drain bias, the heater driver and the demodulator follow their ideal values to within 0.04 mV, except for the drain difference. These values are the pseudo-transient bias points. The settling check fails for the post-filter (NC13 and C15) and for the op amp MID nodes. The MID offsets have no visible effect on the outputs, so only X_OUT and Y_OUT are affected by the unsettled post-filter. The GATE, VSUP_A and heater values match their ideal values. The settling table gives the residue of each slow node. The drain and in-amp pass criteria (1 mV and 2 mV) are far larger than the 49.65 uV drain difference, so they are not affected.

**The rail diode is the stand-in model.** The header of `circuits/afe_eval.cir` names `DSCHOTTKY` as the generic Schottky model for the rail diodes, with V_F about 0.18 V at 3.4 mA and 0.21 V at 10 mA. The B5819W curve was not read. The model is `.MODEL DSCHOTTKY D(IS=5u N=1.05 RS=0.08 ...)`. Its forward voltage is n V_T ln(I/IS) + I RS, with V_T = 25.85 mV at 300 K, so n V_T = 27.1 mV. At 3.37 mA this gives 27.1 mV x ln(674) + 0.27 mV = 177.1 mV. The measured 177.2 mV agrees. At 10 mA it gives 207 mV. The +5VA rail is therefore set by this model, not by the B5819W part. The expected script assumes 0.30 V to 0.45 V for the B5819W. With that range, +5VA at 5.3 V would be 4.85 V to 5.00 V, not 5.12 V.

**Heater headroom.** At 4.0 V the heater driver output is 4.10 V and P5VP is 5.09 V, a headroom of 0.99 V. P5VP drops 36.8 mV from its heater-off value of 5.122 V. R32 carries the extra 6.66 mA, which gives 6.7 mV. The D5 forward voltage rises by 30.1 mV with the same current, because of the diode model above. A real diode gives a different share.

**The drain difference of -49.65 uV in P23a.** The two drain nodes differ by 49.65 uV at vda = 0. The INA828 model (`INA828.LIB`, lines 187 and 188) puts I_B = 0.15 nA on the IN+ path only, and I_OS = 1 fA on IN-. The current in R31 is 7.50015 uA and in R25 is 7.50000 uA, so the difference is 150 pA (0.15 nA). Through 330 kOhm this is 49.5 uV, against 49.65 uV measured. The difference is therefore a model artefact of the INA828 input current, not a property of the circuit. The ABSTOL = 1 pA run gives the same value, as expected for a model current.

**The change of the drain difference with vda.** At vda = 10 mV the drain difference changes to +18.2 uV (P23b, P23c, P23d step 2), a change of +67.9 uV. The pixel gate term at DC is vda / 330 kOhm x (V(GATE) - vgdc) / vga. With V(GATE) - vgdc = 0.994600 V - 0.994583 V = +17 uV and vga = 0.3 V / 120 = 2.5 mV, the term is 10 mV / 330 kOhm x 17 uV / 2.5 mV = 0.206 nA. Through 330 kOhm this is 68.0 uV, which matches the measured shift. The entry does not state this term. The P-23 pass criteria are unaffected, because the drain and in-amp checks use P23a only.

**The INA828 output offset.** The implied in-amp offset is +0.230 mV in P23a, +0.230 mV in P23b and in the heater case. The ideal value is 9.8968 V/V times the drain difference, which is -0.4914 mV in P23a and +0.1800 mV in P23b. The offset is below the 2 mV limit. Its source is not analysed. The vendor offset is not verified here.

**Zero-signal X_OUT.** The bias-table values of X_OUT (-0.030 mV at vda = 0, -0.353 mV at vda = 10 mV, -0.110 mV and -0.100 mV with the heater on) are not settled and not used for the pass. They depend on the path of the pseudo-transient, and they are not a property of the circuit. The analytic settled value is -0.052 mV in every state, from the input current of U26B (5.25 pA through 400 kOhm, the model value) and the input offset of U26B. The settled value is consistent with P-28, which gives the same term at the tens of uV level with settled MID nodes. The state dependence seen in the bias tables is a residue of the stop, not a second physical effect. Its mechanism is supported by the MID and KCL evidence (a) to (c), and it is inferred, not verified.

**Sweep.** The non-monotonic sweep curve of X_OUT is consistent with the same residue, because the stop depends on the bench ramp. The rail values of the sweep are not affected, and the DAC80508 limit (v5 of at least 5.18 V) is unaffected.

**The sweep and the -5 V rail.** The sweep changes v5 only. The -5VA rail stays at -5.131 V, which is set by v5n = 5.3 V. The -5 V rail is therefore not tested here. P-23 accepts this, but a symmetric sweep needs a second run.

## Open points

1. **Settled DC values not simulated.** The tight pseudo-transient `.OP` (P23e) did not converge within 23 min, and the main session stopped it. The settled bias point of afe_eval.cir is therefore not simulated. The analytic value (X_OUT = -0.052 mV) stands in for it. A long `.TRAN` run, which would settle the post-filter and the MID nodes, is the route to a simulated value. It was not run, because P-27 holds the simulator. The owner should decide whether to plan it as a new entry.
2. **Rail diode model.** The header of `circuits/afe_eval.cir` names `DSCHOTTKY` as the generic Schottky model. It says the B5819W curve was not read, and gives V_F about 0.18 V at 3.4 mA and 0.21 V at 10 mA. The hand values with RS = 0.08 Ohm are 177.1 mV at 3.37 mA and 207 mV at 10 mA, which match the simulation. The +5VA and heater headroom results depend on this model. The owner should decide whether to add a B5819W model, then rerun P23a and P23c. The B5819W forward voltage is not verified here.
3. **Entry arithmetic (entry not changed).** The U9A output value 4.099 V and the HSENSE_B value 2.48 V both leave out the 40 uA bleed of the R20 and R22 divider. The corrected values are 4.099857 V and 2.496420 V. Both still pass. The entry is not changed (owner decision).
4. **U10A and U10B inputs.** The +IN of U10A and U10B is DAC2 and DAC3 at 2.4 V. At V+ = 5.12 V, 2.4 V is inside the OPA2196 transition region (2.12 V to 3.62 V). The P-23 rule does not list these stages, but P-33c tests this finding (F-08 of the 2026-10-29 review).
5. **U9A input near the transition region.** At DAC1 = 2.0 V, the input is 0.09 V below the region, which starts at 2.09 V.
6. **HSENSE_B naming.** The netlist drives HSENSE_B from the heater A shunt (IC3, U9A side), as the circuit header says. The P-23 value follows the netlist. The naming is a question for the owner and the board review.
7. **Bench target.** The +5VA target of 5.0 V to 5.2 V needs v5 between 5.18 V and 5.38 V with this model (slope 0.998 V/V). The entry's bench of 5.0 V (smoke run) gives 4.82 V, which is below the target. The circuit default of 5.3 V gives 5.12 V.
8. **Not verified.** The B5819W forward voltage, and the INA828 offset and its input bias current (the model value is 0.15 nA, the datasheet value is not read).
9. **Stopped runs.** P23c_abstol and P23e_op_tight did not finish. P23e was stopped by the main session, which also stopped its server processes. The earlier `SimSrvr.exe` processes of P23c_abstol were idle when last checked. They are not rechecked here, and the owner should confirm that none remain (see the quirks log).
