# Differential amplifier design

This README covers the `differential-amplifier` design. It describes the netlist, the stage formulas, the two simulation profiles, the simulated results, and the wiring problems found. The schematic file `TI-PSPICE.DSN` was not edited. All fixes described here are scratch copies that live in `circuits/`.

## 1. Purpose

The design is the analog front end of a lock-in amplifier channel for a GMOS gas sensor. A differential signal enters an INA828 instrumentation amplifier (U1). The INA828 output feeds a Sallen-Key high-pass filter (U2, C1, C2, R17, R18). That filter feeds a Sallen-Key low-pass filter (U3, R21, R22, C3, C4).

The two filters form a band-pass around the excitation frequency of about 518 Hz. The high-pass corner and the low-pass corner are both close to 520 Hz, so the chain passes a narrow band near that frequency.

The circuit uses one 5 V positive rail and one -5 V negative rail. Both rails are generated by ideal voltage sources in the simulation. The rails ramp up during the first 2 ms of a transient run.

### Supply network

Two ideal sources make the rails. V_V4 drives node N06938 from 0 V to 5 V. R_R14 (3 Ohm) carries that voltage to the +5V net. V_V5 drives node N07080 to -5 V through its reversed terminal. R_R15 (3 Ohm) carries that voltage to the -5V net.

In the bias point the rails read +4.9921 V on +5V and -4.9920 V on -5V. The 7.9 mV drop on the +5 V side across 3 Ohm implies about 2.6 mA of load current. This value comes from the bias point in `frequency_analysis/frequency_analysis.out`. The value was not checked against a load budget.

D_D3 has its anode on -5V and its cathode on +5V. In normal operation the anode is below the cathode, so the diode is reverse biased and does not conduct. It conducts only when the -5 V net rises above the +5 V net by a diode drop. The file does not state the intent. The likely purpose is protection against crossed or reversed supplies. This is not verified.

### The PULSE ramp on the supplies

Both V_V4 and V_V5 use `PULSE 0 5 1m 1m`. The fields mean: initial value 0 V, pulsed value 5 V, delay 1 ms, rise time 1 ms. The source is therefore 0 V until 1 ms, rises to 5 V between 1 ms and 2 ms, and stays at 5 V after that.

The ramp moves the rails from zero to full value over 1 ms. The file does not state the purpose. The most likely purpose is a soft start. This lets the op amp and INA828 models settle from a known state without a large start-up transient. This is not verified.

## 3. Stage analysis

The formulas below use the nominal values from the netlist. Resistor values are exact as written. Capacitor values are exact as written.

### 3.1 INA828 gain

The INA828 model in `C:\cds_spb_home\cdssetup\pspTILibDir\INA828.LIB` places two 25 kOhm resistors from the RG pins to the internal inputs (`RF1 NODE1 RG- 25E3`, `RF2 NODE2 RG+ 25E3`). The resulting gain is set by the external resistor R16 between RG+ and RG-. The datasheet formula is

G = 1 + 50 kOhm / RG

With RG = R16 = 5 kOhm:

G = 1 + 50 kOhm / 5 kOhm = 1 + 10 = 11 V/V

The simulated gain from V(N09301) minus V(N09296) to VDIFF is 11.00 V/V at 50 Hz to 1 kHz (section 5.3).

### 3.2 Sallen-Key high-pass filter (U2)

Tracing the nodes gives this topology. The input is VDIFF. C_C1 goes from VDIFF to N07625. R_R17 goes from N07625 to the output HPF. C_C2 goes from N07625 to N07629. R_R18 goes from N07629 to ground. U2 is a unity-gain follower with +IN on N07629 and output on HPF.

So the roles are:

- C1 = C_C1 is the series input capacitor.
- C2 = C_C2 is the series capacitor between the junction and the follower input.
- R_f = R17 is the resistor from the junction to the output.
- R_g = R18 is the resistor from the follower input to ground.

Nodal analysis of this topology gives the transfer function

H_HP(s) = s^2 R17 R18 C1 C2 / (s^2 R17 R18 C1 C2 + s R17 (C1 + C2) + 1)

Comparing this with the second-order form gives the natural frequency f0 and Q below.

f0 = 1 / (2 pi sqrt(R17 R18 C1 C2))

Q = sqrt(R17 R18 C1 C2) / (R17 (C1 + C2))

Values:

- R17 R18 = 4.64 kOhm x 18.7 kOhm = 86.768 MOhm^2
- C1 C2 = 33 nF x 33 nF = 1.089e-15 F^2
- R17 R18 C1 C2 = 9.4490e-8 s^2
- sqrt(R17 R18 C1 C2) = 307.39 us
- f0 = 1 / (2 pi x 307.39 us) = 517.76 Hz
- Q = 307.39 us / (4.64 kOhm x 66 nF) = 307.39 us / 306.24 us = 1.0038

The high-pass corner is about 518 Hz with Q about 1.0. Because Q is slightly above 0.707, the response has a small peak above the corner. The peak gain of this stage alone is Q / sqrt(1 - 1/(4Q^2)) = 1.158 V/V at about 724 Hz. The simulated stage peak was 12.73 V/V at HPF for an 11 V/V INA828 gain, which gives 1.157 V/V relative gain. This agrees with the formula.

### 3.3 Sallen-Key low-pass filter (U3)

Tracing the nodes gives this topology. The input is HPF. R_R22 goes from HPF to N08401. R_R21 goes from N08401 to N08020. C_C4 goes from N08401 to the output VSAMPLE. C_C3 goes from N08020 to ground. U3 is a unity-gain follower with +IN on N08020 and output on VSAMPLE.

So the roles are:

- R1 = R22 is the series input resistor.
- R2 = R21 is the series resistor to the follower input.
- C_fb = C4 is the capacitor from the junction to the output.
- C_g = C3 is the capacitor from the follower input to ground.

The standard result for this topology is

f0 = 1 / (2 pi sqrt(R1 R2 C_fb C_g))

Q = sqrt(R1 R2 C_fb C_g) / (C_g (R1 + R2))

Values:

- R22 R21 = 4.64 kOhm x 4.64 kOhm = 21.530 MOhm^2
- C4 C3 = 130 nF x 33 nF = 4.290e-15 F^2
- R22 R21 C4 C3 = 9.2372e-8 s^2
- sqrt(R22 R21 C4 C3) = 303.91 us
- f0 = 1 / (2 pi x 303.91 us) = 523.69 Hz
- Q = 303.91 us / (33 nF x 9.28 kOhm) = 303.91 us / 306.24 us = 0.9924

The low-pass corner is about 524 Hz with Q about 0.99. This is higher than the Butterworth value of 0.707, so the stage has a small gain peak near its corner, like the high-pass stage.

### 3.4 Combined band-pass

The chain gain is H(s) = G x H_HP(s) x H_LP(s). Evaluating the product on a fine grid gives:

- Peak gain: 11.08 V/V (20.89 dB) at 520.7 Hz.
- -3 dB points: 379 Hz and 715 Hz. The -3 dB bandwidth is 336 Hz.

These are ideal stage values. They do not include the finite bandwidth of the INA828 or OPAx192 models.

## 5. Simulation results

### 5.1 Why the AC output is zero

The first test gave an AC output of about 1e-21 V. The original circuit was run again over 10 Hz to 100 kHz (`diffamp_ac_wide`). The result was:

- Peak |V(VDIFF)| = 7.25e-18 V at 87.1 kHz, which is still essentially zero for a 1 V AC input.
- Peak |V(VSAMPLE)| = 7.96e-20 V at 46.8 kHz.

The output of the INA828 is therefore near zero at all frequencies. The cause is in the DC bias point of `frequency_analysis/frequency_analysis.out`:

- V(N09301) = V(N09296) = -5.2126 V. The inputs of U1 sit below the -5 V rail, which is -4.9920 V in the bias point.
- X_U1.INP and X_U1.INN, the internal input nodes, are at -2.9919 V. The external pins and the internal nodes differ by about 2.2 V. This means the input protection path between the pins and the internal stage conducts.
- The AC small-signal path through a conducting protection path has almost no gain. This is why the output is near zero.

The root cause is V_V6. Its two terminals, N09301 and N09296, have no path to ground. Only the internal parts of U1 connect them to the rest of the circuit. The DC solver has no reference for the common mode, so it places both inputs at -5.2126 V. This voltage is outside the rail, and the amplifier is driven into a non-linear state.

The two hints in the task are not the cause:

- V_V7 drives M_UN0001. This source has no effect on the AC analysis because its AC magnitude is zero. Its node is connected to nothing else, so it cannot reach the INA828.
- R19, R20, R23 and R24 are dead branches. They do not load the signal path. They do not cause the zero output.

### 5.2 Corrected copy

The fix is a common-mode reference. The file `circuits/diffamp_ac_fixed.cir` adds two resistors, each 100 kOhm, from the input pins to ground:

    R_CM1 N09301 0 100k
    R_CM2 N09296 0 100k

The file also replaces the V_V6 line with `DC 0Vdc AC 1Vac SIN(0 15m {f} 0 0 0)`. This drives the transient run with a 15 mV differential sine. The AC analysis ignores the SIN part. The netlist was inlined into the file so that the fix is self-contained.

The fix was done only in files under `circuits/`. The schematic `TI-PSPICE.DSN` was not changed. The fix must be made in Capture. Add two resistors from each INA828 input to ground, or any equivalent DC reference. The same input drive can then be used.

After the fix the bias point puts both inputs at 0 V. The simulated gain from the input to VDIFF is 11.00 V/V.

The maximum time step was checked at 518 Hz. The run with `.TRAN 0 25m 0 5u` (`diffamp_tran518_5u`) gives a VSAMPLE amplitude of 0.1661 V. The run with a 1 us maximum step gives 0.1661 V. ## 6. Known issues

1. Floating differential input V_V6. The netlist line is `V_V6 N09301 N09296 DC 0Vdc AC 1Vac`. Neither N09301 nor N09296 has a path to ground. The bias point gives -5.2126 V on both nodes (`frequency_analysis.out`, small-signal bias solution). This is the root cause of the zero AC output in section 5.1.

2. Input drive is not connected to the amplifier in the time domain. The line `V_V7 M_UN0001 0 SIN(0.25 15m {f} ...)` drives node M_UN0001. The node M_UN0001 appears in no other netlist line. The `.als` file lists it only with V_V7. The sine therefore never reaches U1. The `.PARAM f` is used only by V_V7, so the frequency list in the `time_analysis` profile has no effect on the signal.

3. The transient input is 0 V in the original design. V_V6 has `DC 0Vdc AC 1Vac` and no transient function. This is why the original `time_analysis` output is zero (section 5.4).

4. Dead branches R19, R20, R23 and R24. The netlist has two 1 kOhm resistors in parallel from ground to N07747 (R_R19, R_R20) and two more from ground to N08320 (R_R23, R_R24). Node N07747 and node N08320 each appear in no other line. The branches carry no current and have no effect. They look like leftover parts.

5. Output range at the design input level. The INA828 gain is 11 V/V. A 1 V differential input would give 11 V at VDIFF. The supplies are +5 V and -5 V. The output cannot exceed about 5 V, so the linear range of the input is at most 5 V / 11 = 0.45 V differential. The true limit depends on the INA828 output swing, which was not verified.

6. Input common-mode range. The inputs of U1 must stay within the INA828 common-mode range. The range was not verified from the datasheet. The bias point in item 1 shows that a common-mode voltage of -5.2 V, below the -5 V rail, drives the input into a non-linear state.

7. Supply protection diode D_D3 has anode on -5V and cathode on +5V. The intent is not stated. The orientation does not conduct in normal operation. This is not verified against the BA220 datasheet.

8. Series resistors R_R14 and R_R15 (3 Ohm) sit between the ideal rail sources and the rails. Their intent is not stated. They carry about 2.6 mA in the bias point, a drop of about 7.9 mV.

9. The low-pass capacitor values are unequal (C4 = 130 nF, C3 = 33 nF). The filter Q is 0.992 for these values. The reason for the unequal values is not stated in the files.

10. Probe names with the bracket form `V([NODE])` are required by PSpice. `tools/run_sim.py` converts `V(NODE)` automatically.

## 7. How to re-run

All commands are run from the project root `C:\Users\LW\Documents\GMOS-LIA\simulations\ti-pspice\ti-pspice`.

Run the original wide AC sweep (10 Hz to 100 kHz):

    python tools/run_sim.py differential-amplifier/frequency_analysis --name diffamp_ac_wide --analysis ".AC DEC 100 10 100k" --probe "V([VDIFF])" "V([HPF])" "V([VSAMPLE])" "V([N09301])" --timeout 900

Run the original transient (the input is zero, see section 5.4):

    python tools/run_sim.py differential-amplifier/time_analysis --name diffamp_tran_orig --probe "V([VDIFF])" "V([HPF])" "V([VSAMPLE])" "V([M_UN0001])" --timeout 900

Run the corrected AC sweep (saved circuit with the common-mode fix):

    python tools/run_sim.py circuits/diffamp_ac_fixed.cir --name diffamp_ac_fixed --probe "V([VDIFF])" "V([HPF])" "V([VSAMPLE])" "V([N09301])" --timeout 900

Run the corrected transient (saved circuit, 15 mV sine, six frequencies):

    python tools/run_sim.py circuits/diffamp_tran_fixed.cir --name diffamp_tran_fixed --probe "V([VDIFF])" "V([HPF])" "V([VSAMPLE])" "V([N09301])" --timeout 900

Run the 50 Hz check over two periods (100 ms, one frequency):

    python tools/run_sim.py circuits/diffamp_tran_fixed.cir --name diffamp_tran50_long --analysis ".TRAN 0 100m 0 1u" --analysis ".STEP PARAM f LIST 50" --probe "V([VDIFF])" "V([HPF])" "V([VSAMPLE])" "V([N09301])" --timeout 900

Run the 518 Hz maximum time step check (5 us step):

    python tools/run_sim.py circuits/diffamp_tran_fixed.cir --name diffamp_tran518_5u --analysis ".TRAN 0 25m 0 5u" --analysis ".STEP PARAM f LIST 518" --probe "V([VDIFF])" "V([HPF])" "V([VSAMPLE])" "V([N09301])" --timeout 900

Each run writes `sim-runs/<name>/<name>.csd`. Read the result with the reader in `tools/csdf.py`:

    python tools/csdf.py sim-runs/diffamp_ac_fixed/diffamp_ac_fixed.csd --summary --signals "V(VSAMPLE)" "V(VDIFF)"

For the peak and -3 dB values, load the file with `read_csdf` from `tools/csdf.py`. Take the magnitude of V(VSAMPLE) divided by the input (1 V for the AC runs, or 2 x |V(N09301)| when V(N09301) is probed alone). Find the peak. The -3 dB points are the first and last frequencies where the magnitude is at least the peak divided by sqrt(2).

For the transient amplitudes, load each section with `read_csdf`. Take half the peak-to-peak value of V(VSAMPLE) over 15 ms to 25 ms.
