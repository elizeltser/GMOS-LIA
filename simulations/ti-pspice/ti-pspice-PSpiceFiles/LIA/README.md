Design folder: `ti-pspice-PSpiceFiles/LIA/`
Profile: `lia_sanity` (`lia_sanity.sim`, circuit file `lia_sanity/lia_sanity.cir`)
Netlist: `LIA.net` (generated by Capture from the schematic page, 27 October 2026, 14:38)
Frozen test copies: `circuits/lia_v2.cir`, `circuits/lia_v2_harm.cir`, `circuits/lia_v2_fin518.cir`
Alias file: `LIA.als`

## 1. Purpose

This design is the analog front end of a lock-in amplifier. It reads the GMOS gas sensor. The input is a sine at the excitation frequency f_osc = 517 Hz, with a 2.5 V offset and a 2 V amplitude.

Two square-wave switched inverting amplifiers demodulate the input. Each channel has a TMUX6136 behavioral SPDT switch (model `SPDT_PREC`). The switch selects either the input sine or a 2.5 V reference. A 50 % duty square wave controls the selection. The op amp then gives a gain of +1 or -1 about 2.5 V, so each channel multiplies the input by a square wave of +1 and -1. An RC filter averages each output.

The X channel uses its reference at phase 0. The Y reference is delayed by a quarter period, so the Y channel is in quadrature with the X channel. The fixed delay of 482.6 us is not exactly a quarter period at 517 Hz. This gives a small phase error d = 0.1785 deg (section 5.2). The settled outputs are:

VX = 2.5 V - (2 Vampl / pi) cos p

VY = 2.5 V + (2 Vampl / pi) sin(p - d)

Here p is the input phase in degrees and Vampl is the input amplitude. Section 8 lists the measured results. Harmonic rejection, non-harmonic interference and frequency mismatch were checked in runs P-04 to P-07.

### 2.4 SPDT_PREC pin order

The subcircuit line is `.SUBCKT SPDT_PREC S1 S2 D SEL VDD VSS`. With SEL low, S1 connects to D. With SEL high, S2 connects to D. In both channels S1 is the input sine N00890 and S2 is REF. The switch therefore chooses between the sine and the 2.5 V reference. The VTH parameter is not used by the model (warning ORPSIM-15256 in the `.out` file).

### 2.5 Signal path

The X channel works as follows. The switch output N00695 is either the reference REF (2.5 V) or the input sine N00890. It drives the + input of U2. The - input N00610 receives the input through R2, and the output returns through R1.

With R1 = R2 and the op amp at a virtual short, the output is:

VX_DEMOD = D + (R1/R2)(D - Vs) = 2D - Vs

where D is the switch output and Vs is the input sine.

- When D = Vs (sine selected), VX_DEMOD = Vs. The gain about 2.5 V is +1.
- When D = 2.5 V (reference selected), VX_DEMOD = 5 V - Vs. The gain about 2.5 V is -1.

The Y channel is the same, with U4, R4, R6 and N01681. The RC filters R3/C1 and R5/C2 average the two outputs. The switch RON of 120 Ohm sits in series with the op amp + input. The op amp draws almost no input current, so this causes almost no DC error.

## 3. Stimulus and timing

### 3.1 Sources

| Source | Type | Netlist entry | Value with defaults | Role |
|---|---|---|---|---|
| V_V4 | Sine | {Vdc/2+ost} {Vampl} {fin} 0 0 {p} | 2.5 V offset, 2 V amplitude, 518 Hz | Input sine |
| V_V7 | Sine | 0 {Vharm_ampl} {f_osc*n_harm} 0 0 {p} | 1 V at 1034 Hz | Harmonic source in series with V_V4 |
| V_V2 | Pulse | PULSE 0 5 0 {t_slope} {t_slope} {0.5/f_osc} {1/f_osc} | 0 V to 5 V, high from 0 s | X square wave |
| V_V6 | Pulse | PULSE 0 5 482.6u {t_slope} {t_slope} {0.5/f_osc} {1/f_osc} | 0 V to 5 V, delayed by 482.6 us | Y square wave |
| V_V8 | DC | {Vref} | 2.5 V | Switch reference |
| V_V1 | DC | {Vdc} | 5 V | Supply |

At f_osc = 517 Hz, the period is T = 1 / 517 Hz = 1.934236 ms. The half period is 0.967118 ms.

### 3.2 X reference (V_V2)

The X reference is high for the first half of each period. The edges have a 100 ns ramp. The high time is T/2 + t_slope, because PSpice counts the pulse width from the end of the rise (P-01). This adds 100 ns to the high time, so the duty cycle is slightly above 50 %.

### 3.3 Y reference (V_V6)

The Y reference has the same waveform, including the extra 100 ns of high time, with a delay of 482.6 us.

### 3.4 Quadrature

A quarter period at 517 Hz is T/4 = 483.559 us. The netlist delay of 482.6 us is 0.959 us shorter. This is the same as a quarter period at 518 Hz, which is 482.63 us. The Y reference therefore sits at 89.82 deg, not 90 deg. This is the source of d = 0.1785 deg in section 5.2.

### 3.5 Frequency match

If fin equals f_osc, the input and both references share one period. At fin = 518 Hz the two frequencies differ by 1 Hz. This gives a beat with a period of 1 s (P-07, section 8).

## 4. Output filter

Each channel has a series resistor of 10 kOhm and a shunt capacitor of 10 uF.

- Time constant: tau = R x C = 10 kOhm x 10 uF = 0.1 s
- Cutoff frequency: fc = 1 / (2 pi tau) = 1.5915 Hz
- The 2 f_osc ripple (1034 Hz) is attenuated by about 650 times (ratio 1 / sqrt(1 + (2 pi 1034 Hz x 0.1 s)^2)).

The filter is loaded only by the capacitor, so the DC gain is 1. A 1 s run is 10 tau long. P-01 showed that a 1 s run starting at 2.5 V (with `.IC`) agrees with a 2 s run from 0 V within 0.1 mV.

## 5. Theory

### 5.1 Settled outputs

A square wave of +1 and -1 has a fundamental of amplitude 4/pi. The mean of the product of the input sine and the square wave gives the demodulated output. For an input sine of amplitude Vampl and phase p, the X channel gives

VX - 2.5 V = -(2 Vampl / pi) cos p

The Y reference lies at 90 deg minus d, so the Y channel gives

VY - 2.5 V = (2 Vampl / pi) sin(p - d)

Define K = 2 Vampl / pi. At Vampl = 2 V, K = 1.273240 V.

### 5.2 Phase error d

The Y reference is delayed by 482.6 us. At 517 Hz this is 360 deg x 517 Hz x 482.6 us = 89.8214 deg. The error from 90 deg is d = 0.1785 deg. P-01 and P-02 give the same value, 0.17849 deg.

### 5.3 Y slew delay

The OPAx192 model has a slew rate of 20.19 V/us (P-01). The Y reference switches near the input peaks, where the step at the demodulator output is about 4 V at Vampl = 2 V. The slew then adds an effective delay of about 100 ns to 110 ns at each Y edge (P-01, P-04). The delay is proportional to the step, and so to Vampl. The VY error is the delay times the signal slope, which is also proportional to Vampl. The VY error from slew therefore scales with Vampl^2.

The total effective Y delay is about 235 ns (P-01). It is made of a constant part of 126 ns and the slew part of about 110 ns (P-04). A delay in the Y reference makes it act later, which reduces its lag. The phase at p = 0 is therefore d - 0.044 deg, about 0.135 deg (P-02).

### 5.4 Harmonic response

Take an extra input term a_h sin(n w t) from V_V7, with n the harmonic number. At p = 0:

- For odd n, VX changes by -2 a_h / (n pi). The response falls as 1/n. At a_h = 0.2 V and n = 3, this gives -42.44 mV (P-05).
- For even n, the mean is zero. Even harmonics are rejected to below 0.01 mV (P-05).
- For odd n, VY does not follow 1/n. The Y timing error gives the same error per volt for every odd n. P-05 measured +0.26 mV for n = 3 and n = 7.

The VX rejection is 1/n per volt of amplitude, which is -9.54 dB at n = 3 and -16.90 dB at n = 7 (P-05).

### 5.5 Non-harmonic interference

An interferer at f_i with amplitude A_i has a mean of zero. Its products appear only at |f_i +/- n f_osc|, with amplitude 2 A_i / (n pi) before the RC filter. The DC error is therefore zero. P-06 shows that the settled means change by at most 0.022 mV for the interferers tested (limit 0.1 mV).

### 5.6 Frequency mismatch

With fin = 518 Hz and f_osc = 517 Hz, the input beats against the references at 1 Hz. The ideal beat amplitude is 1.07809 V (P-07). The 2 f_osc ripple splits into two lines, at 1035 Hz and 1033 Hz.

## 6. Simulation profile and time step

The profile `lia_sanity` runs a transient with a `.STEP` over a parameter. The GUI profile has no maximum time step. Without one, PSpice takes steps of up to 244 us. This gives too few steps per period in the switching circuit, and the demodulator outputs come out 5.6 % low (C-03, earlier netlist).

A maximum step fixes this. The step still leaves a small gain error. For a harmonic n at f_osc and a maximum step h, the error is about (n 2 pi f_osc h)^2 / 12.

| Maximum step | Gain error at the fundamental (VX) | Note |
|---|---|---|
| none (GUI default) | about 5.6 % low (C-03) | Not usable |
| 20 us | 0.036 % | Used for P-01 to P-07 |
| 5 us | 0.003 % | Recommended for the fundamental |
| 2 us | 0.0005 % | Recommended for harmonics above n = 3 |

The error at the third harmonic is about 0.3 % with 20 us (P-05). At the seventh harmonic it reaches about 2 % with 20 us. A 2 us run of 1 s takes about 3 min per step.

The solver options are in `options.inc`: `PTRANABSTOL=1e-5`, `PTRANVNTOL=1e-4`, `ITL4=100`, `ABSTOL=1n` and `VNTOL=1u`. The log warns that the high ITL4 value may increase the job time (ORPSIM-16534).

## 7. Expected values with derivation

These values are for Vampl = 2 V, p = 0 deg and ost = 0 V, with the sine at f_osc.

| Quantity | Formula | Expected | Measured (20 us, P-01 and P-04) | Difference |
|---|---|---|---|---|
| VX | 2.5 V - K cos 0 | 1.226760 V | 1.227224 V | +0.463 mV (gain error 0.037 %, from the time step) |
| VY | 2.5 V + K sin(-d) | 2.496034 V | 2.497005 V | +0.971 mV (total Y delay of about 235 ns: 126 ns constant plus the slew part, section 5.3) |

Here K = 1.273240 V and d = 0.1785 deg. At 2 us, the VX difference falls to +0.007 mV. The VY difference changes by only 0.015 mV with the step, so it is a property of the circuit (P-05 time-step check).

## 10. How to run

From the project root, `C:\Users\LW\Documents\GMOS-LIA\simulations\ti-pspice\ti-pspice`, use `tools/run_sim.py` with a circuit file from `circuits/`.

Baseline run, 1 s from 2.5 V, 5 us maximum step, with 8-digit output:

```
python tools/run_sim.py circuits/lia_v2.cir --name <name> --analysis ".TRAN 0 1 0 5u SKIPBP" --extra ".OPTIONS NUMDGT=8" --extra ".IC V(VX)=2.5 V(VY)=2.5" --probe "V(VX)" "V(VY)"
```

Harmonic run (P-05), with the harmonic step over n:

```
python tools/run_sim.py circuits/lia_v2_harm.cir --name <name> --analysis ".TRAN 0 1 0 2u SKIPBP" --analysis ".STEP PARAM n_harm LIST 2 3 7" --extra ".OPTIONS NUMDGT=8" --extra ".IC V(VX)=2.5 V(VY)=2.5" --probe "V(VX)" "V(VY)"
```

Frequency mismatch run (P-07), with fin = 518 Hz:

```
python tools/run_sim.py circuits/lia_v2_fin518.cir --name <name> --analysis ".TRAN 0 1 0 5u SKIPBP" --extra ".OPTIONS NUMDGT=8" --extra ".IC V(VX)=2.5 V(VY)=2.5" --probe "V(VX)" "V(VY)"
```

Amplitude sweep (P-04), with the step over Vampl:

```
python tools/run_sim.py circuits/lia_v2.cir --name <name> --analysis ".TRAN 0 1 0 5u SKIPBP" --analysis ".STEP PARAM Vampl LIST 0.01 0.03 0.1 0.3 1 1.5 2 2.25 2.5 2.75 3" --extra ".OPTIONS NUMDGT=8" --extra ".IC V(VX)=2.5 V(VY)=2.5" --probe "V(VX)" "V(VY)"
```

Use a new `--name` for each run. The results are in `sim-runs/<name>/`. Analyse them with `python tools/csdf.py sim-runs/<name>/<name>.csd --summary`. Run the analysis scripts in `docs/sim-results/scripts/` to reproduce the numbers in section 8.

The `.OPTIONS NUMDGT=8` setting gives six or more decimal places. Without it, the output has about 1 mV resolution.
